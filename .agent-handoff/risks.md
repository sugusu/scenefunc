# 风险与未知

- 整体 Goal active 不等于无限系统资源或已获训练／付费／投稿许可。训练仍须另审；独立定时任务未建立。不能在平台暂停时假称持续计算。
- 用户没有项目包或审阅者，要求执行者自行寻找。公开专业依据的发现可继续推进，但不伪造对本重建的独立复核；禁止把模型／助手意见当真人签认。没有待用户提供材料的阻断。
- 新许可只覆盖已核范围：Konya研究正文CC BY-NC，原照片／平面另有来源；WikiArch CC0仅元数据，图片逐项许可，检索标注主要来自学生。原型案例的专业文本与本机候选专业标签是不同证据。
- 新三案已经查看设计结果，只作开发来源审查，尚未与既有家族去重。论文URL编号错位已交叉核，米兰个人署名未确认；原始任务书、准确尺寸、原模型与动作均不能臆造。
- 原Windows7卡／165图／原柜回放仍无副本。公开恢复29带需求／545家具只证明对应计数；生成参考不提供专业动作真值。原5已查家族均归开发；dancer别名仍暂定。历史软件UUID不阻碍声明代理身份的重建。
- ACTIVITY是研究者选择的一条四步路径，没有模型决策。局部起居接近收益伴随镜前路径损失，最大空矩形减少；0.6米包络持续不通。2厘米网格、1.8米净高、方形人体和门全开皆假设，不是规范、舒适度或物理可搬运证明。
- REPAIR表面相交0不排除实体包含、非水密网格问题或物理稳定性。4家具代理仍在；灯五点承托不是稳定性。研究者调整初态不能计训练目标或模型成果。
- 实际move工具瞬移且perfect有毫米／0.1度级噪声，后果必须取真实状态。路径包络只核假设下的平面扫掠，不覆盖重量、摩擦、搬运者或关节运动。当前床折叠／窗帘／活动墙没有真实动作验收。
- 检查点只覆盖固定环境、已有对象家具会话的协作保存；未覆盖动作执行中崩溃、模型状态或完整生成。ACTIVITY最终包逐文件核验但未再冷恢复。旧包版本不可静默更改；所有失败／原始回执保留。
- 观察四补丁绑定实际结构和blend；轴对齐房间已验图，曲墙／斜墙未覆盖。REPAIR自身图是第一次修订，最终输入图是ACTIVITY step0；不得混用不同状态图。
- 加载器工程审计通过但预算84／92监督token、1／2样本未匹配。配对元数据和顶层initial_state会被忽略；显式task_context才入输入。training_eligible不会自动被官方加载器执行，须使用审定清单。真实专业正向准入仍0。
- 整屋评价仍草案；独立测试、人评、样本量、基线预算未冻结。普通反馈／输入修复不算训练或跨项目泛化收益。历史DD整体成功unknown；TC有一次截断，提案未执行，不重抽。
- 完整运行后端缺SAM3、SAM3D、ArtVIP、材料资源，不能把现有家具编辑当完整生成。CP311固定165包，bpy wheel标签警告保留；其他环境不改。
- Git曾间歇认证／传输异常，根因未定。以每批git ls-remote精确SHA为发布证据；断网留同一提交不重跑。只在实验副本配置专用密钥，不泄漏凭据、不force-push、不改main／AutoDL。
