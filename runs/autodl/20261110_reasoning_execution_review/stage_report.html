把理由当训练监督，与要求模型每步先讲理由，是两个问题

本轮在已有 Git 审阅之后补读 ECoT 与 ERVLA 的方法、指定附录和固定提交源码，并实际执行轻量预处理函数。没有训练、模型推理或新房间生成。结论是保留现有同材料普通对照，不为“reasoning dropout”再搭一套新架构；现有混合对照与作者方法并不等价。下一次模型实验应区分监督收益、显式理由条件的收益，以及阶段提示/停止协议的收益。

上轮是一次已完成的状态和效果复核；本轮新增了固定作者代码证据、可复跑的预处理执行结果及目标函数检验。工程检查数量不计入场景效果，研究总目标仍未完成。

2. CPU 上得到的实际结果

对作者函数做 AST 提取，保留被执行的方法体，只去掉模块导入和类注册装饰器。使用显式标记的合成序列化输入运行36个预处理条件，以及2个前缀范围选择条件。未把它们转换成训练样本，也不把它们当作38次场景实验。

  • ERVLA：有标注且强制开启时输出所请求的理由字段；关闭或无有效标注时输出空理由及对应输入模式。重复调用没有污染原始输入模板。
  • ECoT：字段丢弃改变实际理由文本；它不等于保持相同理由目标、只改变后续动作是否读到它。
  • ERVLA缓存选择器：一个分支选语义前缀范围，另一个选完整范围。此检查只执行范围选择，未执行注意力或证明梯度行为。
  • 实际24单元、2975个目标token均保留。现有混合控制在三个混合比例下，与两端目标的加权和在数值和梯度上相符，最大误差约2.22×10−16。用的是实际系数和合成标量logit，不能解释为真实模型损失或拟合成绩。

详见完整执行结果。CPU主体耗时约0.90秒，不包括解释器/库启动、源码下载及人工阅读；没有GPU调用。

3. 目标函数：哪些差异被识别，哪些没有

记X为原始要求、当前观察和工具证据，D为可见的决定文本，A为实际工具动作。M是有D标注的单元集合。以下CE保留原始每个token的权重，并区分阶段提示；不把加权CE冒充一个已归一化序列概率。

L_aux = L_D + Σ_i CE_w(A_i | X_i, action_mode)
L_cond = L_D + Σ_{i∈M} CE_w(A_i | X_i, action_mode, D_i)
                 + Σ_{i∉M} CE_w(A_i | X_i, action_mode)

L_mix(q) = q L_cond + (1−q) L_aux,  0≤q≤1.

这个等式适用于仓库既有 mixed_context_diagnostic_v1：每个已标注动作拆成有/无前缀两个副本，系数分别乘q与1−q；D目标仍完整保留。未标注动作在两端相同，因此只计一次。等式成立是线性加权的结果，不是新学习理论，也不保证混合后的策略优于任一端点。

期望目标或全量梯度一致，不意味着不同随机批次、dropout、梯度裁剪和Adam轨迹一致；计算量也不同。44个混合组件与34个端点组件拥有相同目标权重总量，但额外前向计算要计费。作者的字段删除/空理由切换还改变文本目标和输入模式，且ERVLA采用不同动作头，不能由上述等式宣称作者方法与本地目标等价。

24个单元中有10个D目标（8个操作、2个停止总结），另14个没有D。当前两阶段部署却会先尝试生成D。已标注单元上的上下文混合不能消除这14个单元的条件分布差异，也不能生成可信的专业理由。现有标签不得补造或删除。

进一步，若部署理由只由X生成且未查询新的外部证据，它不增加关于任务的新外部信息，但仍可能提供计算中间步骤、改变有限模型的表达和决策。因此不能用“没有新信息”直接否定它；也不能用“文字更合理”证明它改善了动作。必须测真实执行后果。

同材料普通联合生成已有joint_same_material_v1，目标token与系数相同一次连续输出D/A或原本无D的A分阶段提示、边界和宿主控制是否优于普通自回归表达。

这些区分已有一部分写入原实验定义，本轮不冒充首次发现。部署arm名称不能独自证明加载了哪个训练checkpoint；必须同时记录底座、adapter哈希、训练材料和推理配置。普通动作训练是另一种监督条件，不能把separate_direct这个名称直接当作它。

full_generation_bridge只在家具阶段启用所选策略；地面、墙面、天花等使用共同底座，工具侧模型另计。训练材料也全部来自家具操作。它允许把候选放回完整生成流水线评测，但不意味着已经训练了整条流水线。

5. 本轮后的执行选择

不新增“dropout方法”、连续动作头或第二套理由数据库。保留已经实现的同材料联合训练和辅助理由直接动作两个强对照，先补齐固定输入并确认真实模型能拟合、正常执行。恢复输入不是方法成功，不能持续用它替代真实决策实验。

在同一实际起点上，首先记录自由生成的D、动作、原生工具回执及场景后果。原理/计划/完整理由等教师前缀实验仅用于定位瓶颈，不作为主成绩。理由正确但动作错误、工具执行成功却破坏要求、正确起点上不必要修改，要分开计数。以前已有的普通搜索仍应获得相同资产、工具与计算预算。

判定推进的证据应是完整生成中必需实例与关系同时完成、保留原有正确要求，以及总成本改善；新的独立房间必须与训练及反复调试过的家族分离。如果只改善文本或停止格式，收窄主张；如果普通联合训练已经相当，就不为分阶段形式继续扩大投入。该执行选择不等于否定完整三维研究，也没有承诺CVPR贡献已成立。

本轮尚缺：5个固定输入的视图、修订模型的真实训练与自由输出、完整生成运行资格及独立房间效果。当前不请求GPU。旧研究文件未改，新增报告和执行代码位于本轮目录及scripts/autodl。
