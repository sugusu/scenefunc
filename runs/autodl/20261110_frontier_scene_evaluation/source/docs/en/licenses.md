# Task assets and licenses

[中文](../cn/licenses.md) · [Documentation](../README.md)

The release contains 145 tasks: 130 L1/L2 tasks and 15 L3 environments. [Apache-2.0](../../LICENSE) applies to benchmark software. Task assets retain their individual licenses; the collection does not grant a blanket CC0 license to all assets.

Organizer attribution is excluded from candidate inputs. For each active L1/L2 task, read its `attribution/CREDITS` and the original LICENSE/CREDIT/provenance files referenced there. The current-task index is [task-attribution-index.json](../reference/task-attribution-index.json); the file-level index is [asset-attribution-index.csv](../reference/asset-attribution-index.csv). IDs use the current active release mapping.

L3 reference images retain source and license metadata in each task's `attribution/references.json`. External-library sources and licenses are listed in the [L3 asset locks](../../harness/L3/release/asset-locks/README.md). Original Kenney notices remain in the distributed source archives. Unreal Engine is an external licensed prerequisite.

Original source notices are preserved verbatim. Missing, unspecified or unresolved permission remains unresolved. This guide adds no permission and does not override commercial-use, redistribution, attribution or share-alike restrictions. Consult each source record before redistributing assets. See [Third-party notices](../../THIRD_PARTY_NOTICES.md).
