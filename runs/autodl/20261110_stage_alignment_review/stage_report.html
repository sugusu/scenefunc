值得检验的差异

把决策文本用作辅助监督，和执行时先生成决策再据此行动，是两个不同因素。普通多任务交叉熵、推理前缀和任务前缀本身都不能承担新算法主张。当前应比较同监督的直接动作与自生成决策条件动作，并给直接动作方法相同工具及可用于候选搜索的计算预算。

L_aux = sum_i sum_t w_Ait [-log p_theta(A_it | X_i,A_i,<t)] + sum_i_in_I_D sum_t w_Dit [-log p_theta(D_it | X_i,D_i,<t)]

L_cond = sum_i_in_I_D sum_t w_Ait [-log p_theta(A_it | X_i,D_i,A_i,<t)] + sum_i_not_in_I_D sum_t w_Ait [-log p_theta(A_it | X_i,A_i,<t)] + sum_i_in_I_D sum_t w_Dit [-log p_theta(D_it | X_i,D_i,<t)]

这里保留全部24个原样本；只有10个有原始D。不能伪造其余14个标签，也不能删除它们后宣称仍是相同训练材料。当前输入修正不消除源任务与完整生成之间的分布差异。

理论能支持什么

Self-generated D is additional computation, not an independent spatial observation.

Fixed theta; given X, D uses randomness independent of hidden scene truth Z; no new sensor/tool/retrieval result between X and D.

p(D|X,Z,theta)=p(D|X,theta), so I(Z;D|X,theta)=0.

No impossibility of bounded-compute benefit follows. D can reorganize computation. If a tool is queried, its evidence and cost must be included in all appropriate controls.

Teacher-conditioned evaluation does not establish deployed policy utility.

Fix state/request x and the same action kernel p(A|x,d). Let q(d|x) be the teacher-decision distribution on that input and r(d|x) the deployed generated-decision distribution. For downstream utility U(A,x) in [0,1], define g(d)=E[U(A,x)|x,d].

|E_q g-E_r g| <= TV(q,r), because 0<=g<=1. On a finite support, write signed q-r as positive and negative parts, each with mass TV; maximizing the bounded expectation difference selects the positive part.

An oracle-rationale score can differ substantially from self-generated deployment. No small TV, no guarantee. Our data does not estimate this TV; the inequality is an elementary analysis, not a new result. Teacher annotation that saw A can make oracle action accuracy particularly easy.

Training conditioned and unconditioned paths does not imply equal compute.

For conditioned execution p(A|X)=sum_D p(D|X)p(A|X,D). Greedy D followed by greedy A need not maximize that marginal. Two sequential calls and a longer action prefix consume additional prefill/decode compute.

Compare fixed-supervision and cost-quality experiments separately. Never count only A tokens or exclude invalid D calls.

A common geometric preview proves only the predicates it computes.

If a preview computes C(T(S,A)) exactly for its own transition and predicates C, it can reject C-violations before execution. It says nothing about unmodeled semantics, path feasibility or errors in T/C.

The prior ordinary-search result supports explicit endpoint constraints on procedural boxes only. It neither validates all native execution noise nor makes a complete-room certificate.

Furniture-stage supervision can support a full-generation contribution without training every stage.

Hold the other generation stages and resources common, replace only furniture policy, then compare final room outcomes under paired independent tasks.

This is a valid experimental design, not evidence already obtained. Scoring only furniture-stage endpoints would establish a narrower result.

Distilling Step-by-Step：Rationale generation as an auxiliary task while predicting the label directly at deployment is established. The paper also distinguishes rationale-conditioned prediction. Current weighted cross entropy and task routing are controls, not a new loss.

Rechecked abstract and §3.1–3.2, equations 1–4, task prefixes; experiments and appendices not reread this turn.

The controlled profiles and lack of explicit conflict relaxation limit general personalization claims. Memory, functional abstraction and user-conditioned constraints are overlapping ideas.

Read §2.1–2.3 methods, §3 study design, reported primary results and §6–7 limitations. No figure-by-figure review or reproduction.

RoomWright：Already combines usage-driven object/support/interaction planning, executable asset code, geometric layout solving, visual critique and physical validation. 接回完整生成

原生入口顺序为 floor_plan → furniture → wall → ceiling。修正后的 host 只替换家具阶段，其余阶段继续原入口。合法的论文比较可以只改变家具策略，但主要结果必须来自各组继续运行后的完整房间；无需声称每个阶段都由新模型学习。本轮只验证格式路由，未运行该完整流程。
