去除了重复观察输入，并明确“理由帮助动作”需要证明什么

本轮修复了上一轮实际发现的输入超长问题，完成真实 CPU 多模态编码、当前宿主观察函数回放，以及训练目标的有限梯度核对。没有模型推理、参数更新、原生场景动作、新房间或付费 API 调用。目标仍是完整三维场景生成；这里交付的是使该研究可检验的必要实现，不是场景质量提升。

实际解决的问题

旧请求已经包含 CURRENT NATIVE STATE 和工具 schema；第一版公共观察层又追加了相同的对象和参数。其中一个已有完整五视图的状态因总长度超限被拒绝。不能为此删要求、删历史或丢弃这个样本。本次新增显式 canonical_v2 格式：先确认嵌入的对象值与实际行动前状态一致、工具参数与当前 schema 一致，再将这些结构字段移至公共观察块，只保留一份。原任务、历史回执、工具说明、资产映射、知识卡、量测和不确定项全部保留；对象额外的 representation 字段也保留。

可逆核对恢复了全部源 JSON 值，并检查结构块以外的文字、五视图顺序、目标 token 及原 token 系数不变。JSON 格式、字段位置和消息位置发生变化，因此不声称提示语义效果完全等价，也不能从序列化统一推出任务分布统一。旧材料不覆盖；宿主默认仍是旧 append_v1，只有显式指定新格式才使用本轮材料。

当前算法应当检验的自变量

令 X 为实际场景、原要求、知识、视图与工具回执，D 为模型公开生成的决定说明，A 为工具动作或停止提议。同材料辅助组学习 D|X 与 A|X；理由条件组学习 D|X 与 A|X,D。两组保持相同目标、权重与工具。只有10/24个状态有D监督，另外14个仍是直接动作目标；部署每步产生D所引起的覆盖差异尚未消失。不能编造缺失理由，把新数据称为原样等材料。

自由执行必须使用自己的 D 与动作后的真实场景，不能用教师理由或接回教师后续状态。除相同调用预算的机制诊断，还须报告辅助组直接输出动作的低成本部署。已知知识底座和普通规则／搜索继续保留。本轮没有新训练；相同格式并不修复此前启动的 LEARN 使用 action_only 与 paired、监督内容不等的问题。

理论核查：联合监督、边缘正确率和整屋结果是不同目标

pθ(D,A | X) = pθ(D | X) pθ(A | X,D)
qθ(A* | X) = ΣD pθ(D | X) pθ(A* | X,D)
∇ log qθ(A* | X)
  = E[D | X,A*] { ∇ log pθ(D | X) + ∇ log pθ(A* | X,D) }

这是一条标准边缘化恒等式，不是新理论。只要动作条件模型也依赖θ，两项梯度都要保留。若只在教师D下拟合A，或者只优化D的分数，并没有直接优化自由生成理由后的边缘动作正确率。本轮用共享参数的有限概率表，分别核对单参考动作和两个合法动作的情况：后验加权的联合梯度与直接自动微分一致，有限差分最大误差约2.30×10⁻¹⁰；只保留D梯度的误差分别约0.560和0.487。这是数学检查，没有训练模型。

现有按家族／成分加权的 token 损失也不自动等于未加权联合对数似然，更不是上述边缘目标的已证明估计器。多个三维行动都可能合理；复现某个参考动作的概率，与执行后满足完整要求的概率还要区分。若定义终态成功事件，检查器必须独立于模型的自我声明，且“未知”不能当作已证实成功。当前仍缺少完整整屋验收，不能用该公式绕过这个缺口。

TRICE §2、附录A提供了直接近邻：它考虑理由的边缘化与后验抽样；主推导的答案提取是与θ无关的确定函数，因此只保留理由分数项有其前提。本轮没有指出该推导错误。将其搬到可学习动作分布或真实场景轨迹，必须重新说明变量、检查器与计算代价，不能把已有方法改名当作三维创新。

参考实现核查及使用边界

完整读了固定提交 2b627dd 的 TRICE参考笔记本16个代码／文字单元。其四个模型后端接口是未实现占位，需要自行接入。第9单元将非负权重送入 log_softmax 后交给重采样器，而API合同要求归一化的对数概率。这给出与按权重比例抽样不同的边缘分布。

固定四样本例中，近零权重项按原表达式仍获得约0.0623抽样概率，权重归一化应约2×10⁻¹¹；期望梯度系数最大偏差约0.0778。这个结论来自原表达式AST、API合同和有限精确期望，没有运行JAX/TFP采样器、模型或原论文实验，也不否定原论文实验。第三方源码未修改；原文件、许可证、提交和SHA均保存。当前不因此引入新的MCMC训练分支。

对研究路线的实际影响

观察去重是工程修正，辅助理由监督和理由条件预测已有前作。当前值得保留的研究问题仍是：同样知识与工具下，模型能否依据用途和真实空间条件作出合适决定，并在连续生成中保住其他要求。自生成说明只有带来真实终态收益或同等质量下更低总成本，才有进一步投入理由。解释好看、对错误说明敏感或复现参考动作，都不能替代完整三维结果。

本轮消除了一个实际输入阻碍，并没有完成研究准入：另外15个状态仍缺完整原图；部分状态缺理由条件监督；源任务、系统提示和新原生整场生成的分布仍不同；Git中的LEARN缺最终回执；同材料训练及独立项目整屋收益均未建立。本轮不申请GPU，也不将9个可编码状态替换为缩小的正式训练集。

下一步以缺失输入和已有训练收尾证据为具体对象继续核对，保留当前材料与同一方法问题；不再靠新增格式版本或标量检查数量宣称研究效果。已有测试足以覆盖本轮改动，后续只有新故障或新改动才重跑。
