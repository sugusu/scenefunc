2．为什么不把集合似然包装成新算法

RANDOMER（ACL2017）§4–5已经比较程序执行的RL与边际似然，并处理偶然答对的程序；MAPO（NeurIPS2018）§3–4已经利用高奖励轨迹记忆及缓冲区内外采样。因而“正确三维动作有多个，所以求和学习”只能先作为成熟基线。普通搜索和奖励检查也必须足够强。

从MAPO固定源码读到：AllGoodReplayBuffer只保存正回报、终止且未重复的程序；回放计算模型概率和总概率，再用于内外权重。其概率裁剪会改变原目标，不能保留裁剪却仍笼统声称完全无偏。源码是Python2/TensorFlow时代实现，本轮未运行官方训练，也未把论文数字迁移成三维预期收益。

3．训练目标必须与完整任务相连

令X为原始要求和实际可用观察，D为决策提议，A为可执行动作，ω为工具内部输出，τ为完整轨迹。G(X,ST)取真、假或未知；未知不计成功。目标是相同总预算下的完整任务完成概率：

J(θ;ψ₀) = E[1{G(X,S_T)=true}],  (τ,ω) ~ p(π_θ, κ_ψ₀).

现有监督首先保持原始24单元和原token系数：10单元有原始D，14单元仅有A；19单元恢复了原观察，另5个仍缺失。这三个数不能互换。缺D不编造，缺图不拿新图替代再称同源对照。辅助D、直接A与自身生成D再A，必须使用同样原始材料和参数初始化；直接A获得节省下来的推理预算做普通候选搜索。

L_aux = Σ l_A(X,A) + Σ_(有原始D) l_D(X,D)
L_cond = Σ_(有原始D) l_A(X,D,A)
       + Σ_(无原始D) l_A(X,A) + Σ_(有原始D) l_D(X,D)

这属于标准监督目标的受控拆分，不是新损失。部署不能把老师D注入条件组，也不能从旧轨迹逐轮重置到正确状态。应让每组使用自己的真实编辑结果获得后续观察。

4．集合边际似然成立的前提

固定可复现后端，令B是同一任务/环境下的、不重复的、完整验证成功的终止动作序列集合。只有B真的包含于完整有效解时，才有：

0 ≤ P_θ(B|X) ≤ P_θ(完整成功|X)
L_B = −log Σ_(τ∈B) P_θ(τ|X)
∇L_B = −Σ_(τ∈B) [P_θ(τ|X)/P_θ(B|X)] ∇log P_θ(τ|X).

空B不能伪造正例；只检查支撑或碰撞不能建立这个前提。动作字符串不同、参数数值相同、三维结果等价是三件事；等价类概率必须把所有成员的概率相加，不能任意取一个代表或用候选频次代替。当前只有观测支持，不存在已准入的完整B，因此代码没有计算一个看似有效的MML成绩。

原来的加权token CE用于保持监督质量和家族权重，但exp(−加权CE)一般不是归一化的动作概率。若将来实现边际似然，轨迹概率须来自完整的原始自回归概率和终止事件，家族权重放在每个样本目标外面；不能偷偷改变原对照的权重后仍称同一个实验。

5．同一模型做动作与工具判断时，必须界定谁在学习

实际RPC从既有SceneBuilder8B检查点加载工具VLM；它不是免费的确定真值接口。若只训练动作adapter而冻结工具服务，研究的是在相同工具下的决策收益。若工具也启用新adapter或同步更新权重，就同时改变了观察、资产估计及环境转移，不能只归因于决策机制。

若双方共用可更新θ，且奖励没有直接θ依赖：
∇J = E[R Σ_t (∇log π_θ(A_t|H_t)
                + ∇log κ_θ(ω_t|H_t,A_t))].
若κ=κ_ψ₀冻结：工具项不属于θ梯度，保留动作项即可。

这是分布求导的标准结果，不是新定理，也不禁止固定工具的策略学习。建议第一轮明确冻结工具检查点、adapter关闭状态、提示与解析器，并保存哈希。若研究共享更新，就另设相同能力的共享更新对照，不能混在一起。

源码还纠正了一个容易出现的误判：placement_noise.py不是每次无种子抽样，而是由输入姿态构造种子，因此该分支不能用来证明重复执行随机。检索映射、渲染、模型解码或其他后端是否随机，需要实际证据；此轮没有重新运行以制造随机性结论。

6．可以直接审查的完整执行算法

  1. 冻结原描述、必需实例和关系、候选资产与工具版本；无法验证的条目保留未知。
  2. 从当前实际场景构造两组相同可用观察。条件组先生成D，直接组输出A；D始终是提议。
  3. 所有组共享动作和有界联合编辑能力，在副本执行，完整累计动作模型、工具VLM、检索、渲染、失败和回滚成本。
  4. 检查完整候选的要求保留、身份、几何和新增目标；允许有界联合编辑中的临时退步，不能强迫每一步都立刻提升布尔指标。
  5. 提交通过共同规则的候选，继续读取它自己的真实场景。预算结束、拒绝、缺物体和未知均保留分母。
  6. STOP只表示策略要求结束；只有完整冻结任务验证通过才算成功。最终比较完整场景质量与总预算曲线。

这个执行循环本身仍有反馈、搜索和回滚的直接先例。它的作用是让候选机制受到公平检验，不能作为主要创新。只有在独立房间中，条件决策超过同源辅助监督、普通搜索和强通用反馈，才值得进一步研究三维特有的表示或训练机制。

7．当前取舍与资源结论

保留原始同源训练对照，不在现有局部轨迹上启动结果奖励训练；先固定工具侧模型边界。集合似然纳入已知方法清单，待真正有完整验证轨迹后再决定是否需要。当前未确认新颖算法，未证明学习收益，也没有终止整个研究。

整场入口仍缺任意新文本CLIP检索能力、索引映射溯源和完整语义覆盖；不能因为单资产管理器跑通就宣布资源和算法准备充分。先解决这些具体公共前提，下一轮应验证完整场景，而非继续制造局部修复样例。当前不需要为写报告或继续源码阅读新增资源。
