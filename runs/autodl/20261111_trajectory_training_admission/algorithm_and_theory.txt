2026-11-11｜完整三维场景生成：轨迹压缩、训练目标与可证明范围

目前确定的是可执行的普通训练基线及其证据边界；尚未证明新的 Agent 算法优于它，不能称为 CVPR 主创新。

1. 本轮算法实际做了什么

输入是同一个真实网格开发房间上，之前实际生成的 B0、B1_repaired 两条四步模型轨迹。B0 也是模型轨迹，不能因其重复动作就把它写成确定性规则；确定性几何搜索是原实验的 B2，本轮没有用它冒充模型样本。原 B1 的基础设施失败仍保留，无答案可转换。

固定公开 Scene-Designer a0565e50ed7d32c0e09132b9311c0b9b91165405。执行原 candidates/deletable_turns，只允许删除同对象片段的内部动作，首尾保持。每条轨迹有两个可删内部位置；枚举其四个子集，共八次回放。从原冻结 checkpoint 分别重建，不改变物体 ID、资产、坐标、噪声或评价阈值。通过既有 bridge 调用未改写的 SceneSmith move 方法，共 24 次移动工具调用及八次状态恢复。不是八个独立房间，不是新模型 rollout。

比较 E：最终世界投影完全相同；比较 C：每个保留动作的输入世界与原记录相同，工具返回 JSON 也相同。世界投影含全部实例、模板、资产来源、几何哈希、房间与支撑/坐标元数据；不含删动作后理应改变的日志、调用计数。不能把此投影说成完整运行时或隐藏物理状态。

实测 E 为 8/8，C 为 6/8。B1 删除第二次有效移动后，原本应返回 no_movement 的后续重复动作变成成功移动；终点虽相同，保留反馈已经改变。旧输入图像也对应不同中间状态。该子集不能直接搬运旧反馈或旧解释。

后置解释性强对照：只删原返回 no_movement 的可删内部动作，再用同一回放表校验，B0 从四步到两步，B1 从四步到三步，与枚举出的最短 C 合格子集一致。这是普通规则，不是学习式方法的胜利；规则是在查看结果后补充，今后可冻结使用，但不能称为本轮前瞻性独立检验。

2. 能证明的命题及不能推出的结论

设确定性转移为 s[t+1]=T(s[t],a[t])，固定用户任务 u，原轨迹 tau，候选删减轨迹 tau'。若完整的任务有关状态 s_T'=s_T，且任务评价 G 仅依赖 (u,s_T)，则 G(u,s_T')=G(u,s_T)。这是代入等式得到的普通事实，并不意味着 G 变大。若原末态失败，单纯保持末态的压缩仍失败。若 G 依赖交互历史、临时例外、执行次数或隐藏状态，该推论的前提不成立。

本轮只证明上述世界投影相同；不证明全物理状态相同。两个末态重新计算的家具网格表面相交分别为 6 对、5 对，与原记录一致。工作/用餐同时可用的既有有限候选池仍未找到解；这不是连续空间无解证明。语义、人体使用、材质、美观等未知项保持未知。新完整场景成功标签为零。

即使 E、C 都成立，也不能推出训练后的策略行为等价。模型输入还有历史记忆 m[t]、任务解释和图像 o[t]；删步骤会改变这些条件。旧解释可能引用已删除的试错。需要在新历史上重建记忆、核对同状态图像，再重新标注或不监督解释。公开压缩器已经有这些思想；本轮没有发明它们。

3. 原始 SFT 监督目标

完整阅读并实际调用公开 sft_dataset.build_step_samples 和 _build_messages；没有构造 processor、模型、optimizer 或 Trainer。原目标是 assistant span 的普通自回归交叉熵：

L_BC(theta) = - E[(x,y)~D] sum_j 1[j 属于 assistant 目标] log pi_theta(y_j | x,y_<j)。

默认消息同时包含采集解释与工具调用；显式 no_thinking=True 的消息仅保留工具调用。当前 train_sft.py 构造 dataset 时没有传这个开关，不能声称本轮 CLI 已开展 actions-only 对照。labels 只把 prompt 置 -100；代码没有在这里根据完整房间任务成功来过滤样本。不能由此推断作者的 OTA-35K 有坏样本：生产数据筛选可能发生在读取器之外，原始 35K 轨迹本轮并未取得。

两个四步摘录都能被原读取器解析成四个样本。但首步记忆为空，因为原加载器从阶段轨迹开头累积工具结果，而这些摘录省略了真实生成前缀。用原 memory handler 重放 checkpoint 中真实的 12 条前缀调用，可恢复 9 件已放家具和相关资产库记录；本轮没有伪造带图像/解释的前缀，也没有把这些摘录准入为独立 SFT。这个结果是本地数据整理限制，不是作者读取器的故障。

首步之后的六次模型输出本来就没有 think 段。适配器第一次误以为每次都有解释，失败后保留脚本和 traceback；修正为有原文则提取、没有则留空，未生成新解释、未换样本。另一次包装失败是系统没有 /usr/bin/time，未启动 Python 子进程。两项基础设施失败都记录，不能当作模型失败或隐去重跑。

4. 可实际采用的普通训练与选择算法

输入必须有：原文任务 u、真实起始场景及资产版本 s0、实际工具调用/结果、对应的动作前图像、完整前缀或有来源的初始化状态，以及独立评价得到的要求真值。

先按对象/资产身份校验构造前缀，再选择目标：
  A. 完整生成正例：只有完整任务检查通过、几何与语义覆盖明确的整条轨迹可标此类。
  B. 局部工具示范：工具后置条件已验证，但完整任务未知或失败；只可声明局部能力，不能换成完整场景成功。
  C. 诊断负例：存在违反要求、陈旧反馈或循环；保留证据，可用于检查或未来成对训练，不能直接模仿为正解。
  D. 未验证：缺图像、缺前缀、语义歧义或物理未知，不按成功处理。

压缩是 B/C/D 分类之后的独立变换。只在作用域支持、完整子集回放通过时删除；重建剩余历史和图像对应；解释重新标注或完全不监督。不能通过删除失败检查、删难放物体或改任务来取得 A。

如果采用成功过滤自训练，L = -sum_tau w(u,tau) log pi_theta(tau|u)，其中 w 的成功判定要覆盖真实任务。ReST-EM 已有此类奖励加权训练，Re-ReST 已有借反馈修正失败样本，不能重新命名为新算法。若当前候选池的成功权重全为零，正例集合为空；压缩不会创造正例，需要普通求解器、真实纠正示范或新探索。不能据此断言模型分布中永远没有正确解，也不能把理想化 EM 的单调性直接搬到有限样本、近似优化和有误差验证器上。

若有同一 (u,s) 下多个经验证可接受的动作集合 A_plus，可用普通集合似然：
L_set = -log sum_{a in A_plus} pi_theta(a|u,o(s),m)。
这是标准边缘化，不是新损失。A_plus 必须有外部证据；不能由待训练解析器自己生成所谓真值，也不能仅凭一条错误动作就把所有未试动作判好。文字程序正确与否、工具是否执行、房间是否达标仍分开评价。

5. 对当前研究主张的影响

本轮支持：有真实工具和状态证据时，能审查训练目标是否忠实，普通规则能够解释已有重复压缩收益。它不支持：压缩失败轨迹能使完整房间生成更好；修好工具返回就等于学会空间设计；或日志/解释更长就代表因果推理更强。

值得继续的任务仍是用途条件下的完整场景设计：把实际用户需要的共同占用、持续保留与可变化条件落实到原生物体和几何。当前尚未证明这项任务需要超出普通需求解析、联合几何求解及其示范蒸馏的机制。下一次训练若开展，必须把这些普通方法放到共同数据、共同动作与总预算下；完整房间、原要求保留、误改、未知项和总成本是结果指标，步数只是机制指标。

已有工作说明可组合组件本身不等于主创新。当前不申请新 GPU/高内存、不扩大调用；本轮只做证据充分的 CPU 原生重放和原读取器运行。研究目标保持未完成，不承诺录用，也不把本轮审计包装成新的生成系统。
