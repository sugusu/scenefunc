新增 critic_task_context.py 将 buffer.prompt 以保留原文的 JSON 字符串传给最终

2. 必须分别定义的学习量

U：原始任务与用户明确的取舍条件；不能被模型的计划替代。
H_t：当前实际场景、允许的观察、已执行工具和历史，含未验证项。
Z：用户偏好存在歧义时的外部用途/上下文解释，真值并不自动可得。
D：策略自己生成的决策提议。D 可能错，不能作为已经发生的几何事实。
A：可执行动作或停止提议。T 是冻结共同工具后端。
C_phi(U, I_1,...,I_K)：条件排序器；Q_U(S) 是想评价的任务质量。
G_V(U,S)：在声明检查范围内，全部原始要求均被覆盖且验证为真。

Z 与 D 不是同一个随机变量。RPR 研究的是给定/推断偏好上下文后的条件评价；
一个策略先写 D 再行动，不会因此自动获得正确的用户偏好解释。
更好的条件排序准确率，也不等于生成器已经提出了可行的完整房间。

3. 从相关论文能可靠使用的理论，以及不能推出的结论

RPR 的上下文分解是普通的加减同一项和三角不等式。设偏好效用差为 Delta_z，
估计为 hatDelta_z，真实/估计上下文分布为 p_z、hatp_z，则

 |sum_z p_z Delta_z - sum_z hatp_z hatDelta_z|
 <= sum_z p_z |Delta_z-hatDelta_z|
    + sum_z |hatDelta_z| |p_z-hatp_z|.

如果另外有 |hatDelta_z| <= M，第二项才可进一步界为 2M TV(p,hatp)。
这不是无需假设的统一误差保证；没有标定效用差尺度、没有真实上下文、没有验证
条件评价误差时，不能把这个式子代入数字宣称三维生成的性能下界。
来源：RPR §3；本轮阅读 §3–5、附录 C 和 D.1 的指定部分，未声称读完全部 35 页。
https://papers.nips.cc/paper_files/paper/2024/file/82acbbc04435f6c1e7f656b1cbe4ad82-Paper-Conference.pdf

另一个直接决定实验设计的普通分解是候选覆盖与排序误差。令 S* 为允许空间中
最优场景，S*_B 为固定有限候选池 B 中最优场景，hatS 为用估计质量在 B 内选出的
场景。如果对 B 中每个候选都有 |Q_U(S)-hatQ_U(S)| <= epsilon，则

 Q_U(S*)-Q_U(hatS)
 = [Q_U(S*)-Q_U(S*_B)] + [Q_U(S*_B)-Q_U(hatS)]
 <= delta_B + 2 epsilon.

证明第二项：依次加减 hatQ_U(S*_B)、hatQ_U(hatS)，中间项因 hatS 最大化估计
质量而非正，两侧各至多 epsilon。若选择器只达到估计最优 eta 以内，再加 eta。
本轮未估计 epsilon、delta_B、eta；对部分几何代理的保证不能替代整场 Q。
这说明：仅改 Critic 无法补回候选池里根本没有的正确房间；只增加候选而不解决
错误用途解释，也可能稳定选错。该分解是标准有限集合选优分析，不是新定理。

4. 现在可研究、且不把普通基线削弱的算法

输入冻结为原任务 U、建筑和候选资产身份；所有方法共享真实原生工具 T。
从同一初始场景开始，执行完整五阶段生成，而不只对已摆家具移动坐标。
执行失败和未知项保留，资产少放不能通过删掉分母得到高完成率。

政策比较沿用同来源控制：
 A0：直接动作，原始动作标签；可以把省下的推理预算用于普通候选搜索。
 A1：增加相同原始 D 的辅助训练，但部署仍直接动作。
 A2：相同原始 D/A 标签，部署先生成自己的 D，再基于 U、H_t、D 产生 A。
三组都使用相同的任务透传 Critic，或都使用相同原生 Critic；不能只给 A2 补上下文。
同一组表示实验内不同时改变终态奖励、动作权限、资产池或工具模型权重。

对完整轨迹可以写
 pi_theta(D_t,A_t|U,H_t)
 = pi_theta(D_t|U,H_t) pi_theta(A_t|U,H_t,D_t).
教师 D 的条件交叉熵只是训练目标；部署时必须用自己的 D，不能喂入事后正确解释。
源数据缺少 D 的样本仍按既有动作目标处理，不编造推理标签。原始家族/组件权重
沿用已验证的 phase_objective，不按重分阶段后的长度偷偷改权重。

每一步：观察当前真实状态；直接提议动作或先写决策；在场景副本中执行有界单项/
联合候选；保存原生工具返回；检查原始要求、身份与副作用；提交允许候选并继续。
普通搜索获得相同上游修改和回滚权限，不能只给 Agent 多步行动。停止仅是一个
动作提议；通过完整任务检查才记为验证成功，未知不是成功，也不充当偏好平局。

如果以后比较条件 Critic 训练，普通条件 pairwise logistic loss 就是必要基线：
 L = log(1 + exp(-y [q_phi(U,S_a)-q_phi(U,S_b)]))。
只使用具有相应来源与适用范围的可靠标签。RPR 已覆盖条件反转的数据结构；不能
把“场景替换回答”命名为新算法。未知、平局、格式失败分别保留。

5. 要识别的收益、当前证据和下一步决策

可检验的候选仍是：学到的决策表征是否帮助系统选择适当的可变上游决定，并在
完整生成中以相同总成本取得更好的原始任务完成度，且超过同标签辅助训练和普通
搜索。D->A、任务透传、图像排序、GRPO、回滚单独都不是新贡献。

先用公共候选池区分排序能力与候选覆盖；这是诊断，不替代各政策自己连续执行
整场。最后按新房间/描述来源隔离，记录完整要求、未知覆盖、几何、改动规模、
总模型 token、工具侧 VLM、检索、渲染、失败候选和实际耗时。

现有 24 条单步监督、72 个开发决策的来源和覆盖限制沿用旧审计，不重新包装为
本轮数据扩展。没有新增完整场景成功标签或独立人工偏好标签，尚无训练收益。
无需为本轮编码检查新增资源；本轮也不构成大规模训练已就绪的声明。

值得继续的是完整后端上的同源、同信息、同预算机制检验。本轮补齐了一个会混淆
结论的普通控制，但不能据此承诺 CVPR 创新或将目标缩成提示接口项目。
