当前驱动遍历 floor_plan、furniture、wall、ceiling；配置中的 manipuland 没有驱动入口。家具生成工具明确只生成落地家具。不能把四阶段结束等同于包含指定桌面物体的完整生成。

已把实际配置预检接入生产包装器，在服务启动之前拒绝这些路径。没有创建模型、调用 API 或生成场景。这修正实验资格判断，不构成新算法，也不证明更改配置就能完成任务。

对算法比较的影响

决定条件化、等材料辅助监督直出动作、普通搜索必须共用真实完整能力；不能让某组缺少小物件生成或让其他组使用未计费的图像模型。下一步应复用上游的小物件阶段与明确的本地资产路径，先验证完整输入的必需实例与关系，不能删除要求换取运行。
