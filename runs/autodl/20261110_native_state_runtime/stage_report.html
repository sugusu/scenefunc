论文和代码对照后的取舍

当前明确检验：同样的知识、目标和判断监督下，让动作读取自己生成的空间判断，是否比直接动作预测改善整场要求或成本。这里使用普通条件交叉熵，没有新增损失函数或性能保证。

Scene-Designer §3.1、D.2 已有观察—思考—动作监督，也保留有后续作用的中间操作。因此新增判断文字、压缩轨迹不能独立承担创新。Distilling Step-by-Step 提供辅助判断学习的强对照依据。

GALA 附录C 明确区分训练时利用已知目标姿态选参考物体与生成时的代理选择。这个边界提醒我们：教师给定上下文中的动作拟合，不能直接当成自由生成的效果；本文贡献和我们的机制也不相同。

下一次模型对照的关键仍是：使用各组自己的真实后续场景，比较必需物体、用途关系、已满足要求保持和全部运行成本。保留同知识基座、普通规则/搜索以及相同判断监督的直接动作组；不能只用动作监督较少的弱组证明“判断有用”。当前全部材料属于开发数据，停止决策的小信号不足以支持CVPR主张。
