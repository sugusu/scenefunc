设计决定的条件与执行证据

2026-11-10 · 固定 Git 来源 75fc783f86d4fea78714639e110fbe77476ee106 · 本轮零模型调用、零训练、零场景编辑。

现有材料确实包含用途与状态的交互，但普通量测规则已解释已支持的编辑／停止标签。下一步仍应检验同材料配对学习能否改善实际完整场景；这里没有确立新的算法或专业偏好收益。

实际完成的核查

逐项读取并绑定全部 24 个状态、6 个项目家族。8 处来源理由对应 5 项原则；22 个动作状态链接到 8 份已存执行后果记录。2 个终止状态另有输入中的当前量测与终态来源引用。复核器重新校验 81 份来源哈希，并从原始输入重算条件表。专业原则有出处，具体位姿及操作次序仍主要是研究者重建。

来源结果保存了实际执行与副作用，但整段执行后果不能归因于其中任意一步。是否存在原生回执、是否通过局部规则、是否获得专业整屋认可，是不同字段。本轮没有重跑物理引擎。

近邻方法与源码边界

  • GALA: Geometry-Aware Language Model for Controllable Object Arrangement：Point-cloud grounding, geometry-conditioned placement and plan/place/verify are existing capabilities. Our hypothesis must concern when a design decision applies, beyond better pose prediction.
  • Scene layout via conceptual design：Selecting a constraint or upstream decision to change after feedback already has direct scene-layout precedent. Termination by removing constraints must not be confused with retaining all user requirements.
  • Scene-Designer: Learning Design Intelligence for Agentic 3D Scene Generation：Legitimate teacher supervision is not test-time evidence. Merely adding a reason before a tool action is insufficient differentiation.
  • DesignAgent3D: Interactive 3D Scene Editing via Designer-like Multimodal Reasoning：Relevant for intent grounding, but this overview does not establish it as a direct trained furniture-layout decision baseline.

GALA 源码固定在 ab280a08ccffffe14f54e44132dc22d87873071e。本次读到的放置分支把指令重试上限固定为 1，随后重生成守卫要求循环索引小于 0，因此此版本该分支不可达。这里只核了控制流；没有运行 GALA，也不能由此否定论文成绩。保留 Apache-2.0 LICENSE 与 NOTICE。

算法和理论的实际位置

当前可执行假设仍是相同理由、动作和信息下，比较分开学习与正确配对学习。监督损失是普通自回归交叉熵，几何与规则是共同工具。拟议收益必须来自把经验适用条件落实到当前对象和真实执行结果，而不能来自更多监督、答案前缀、不同工具或更宽的预算。

有限表格只能证明此处两类输入都与标签有关；它不能证明学习、理由生成或新的因果机制不可替代。测试时的理由必须由模型生成，原任务与实际回执保持可见，最终用执行后的完整需求和保留情况评分。模型学到一种示范，不等于其他合法设计错误。
