The caller still owns native stage handover, finalizers, SDK tool-call cap,
assets/cold branch state, original requirement evaluation and hard subprocess
timeout. Model loading, raw teacher-forward/training and outside-scope export
costs need separate records. The shared ledger counts admissions; it does not
certify neural execution, model identity, image numerics or full scene quality.
Existing backend limits are preserved and may stop before remaining aggregate
resources can be fully used. This is a conservative common control, not a
learned or optimal resource allocator.
