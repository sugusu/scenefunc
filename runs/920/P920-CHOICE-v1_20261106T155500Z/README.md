这是一个项目的四种输入条件，不是四个独立项目。两适配器都见过其布局和动作；给定候选及数值条件的识别远易于自主设计。即使全部选对，也不能证明完整房间生成或专业经验学习有效。不同任务格式、标签绑定和语法均可能影响结果，不能凭本诊断确定旧整屋失败的单一原因。
