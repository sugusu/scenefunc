# Michelet：家庭变化后的房间用途转换

完成一条有来源、可回放的研究迁移记录：移除不再需要的原床，添加办公桌和椅。三步真实工具动作、四次五视图观察、前后状态、冷恢复和三维导出全部留档。它不是设计师历史操作，也尚未成为正向专业训练示范。

[设计师访谈报道](https://www.nevertoosmall.com/post/designing-small-spaces-for-families)支持家庭变化与卧室转办公室的关系；[原项目介绍](https://www.nevertoosmall.com/post/michelet-paris)明确原项目有台阶和垂直叠置空间。这里采用50m²单层10×5m研究壳、人数三变二及替代家具，均非原始测绘。报道不能证明设计师当年采用了本次删床、加桌椅的顺序。

**测量解释纠正：** 冻结点`former_bed_side=[2.45,1.25]`实际位于旋转90°旧床的西端，并非侧边。旧床两侧净空约0.323m，通用左右侧探针均不可达。因此`former_bed_approach_before=true`仅说明床端点可达，不能证明初态三人睡眠可用。没有改点、改场景或删除失败结果；详见PROBE_INTERPRETATION.json。终态桌正前及椅正前通用点也失败，不能用椅侧点通过代替完整办公验收。

## 数据用途

一条已有知识决定首次对应实际三步；理由只在第1步作为整个用途转换的依据，第2/3步只记录普通动作。每组4个候选样本，5个不同JSON，输入绑定实际五图和对象状态。尚未用官方加载器编码，未并入已冻结CURATE数据，未训练；源知识、合法动作、条件效果、专家偏好分别记账。任务明确允许移除旧床，其他家具不可编辑，所以不能据此证明开放设计策略选择。
