本轮从已归档的AIR-v1终态恢复同一房间，仅将原衣架向+Y移动约0.35米。它通过事前冻结的条件：原七个固定点在0.4、0.5、0.6米方形代理下均可从入口到达，衣架至少一整侧五点可达。北侧接近同时损失，因此不能解释为全面更优、专业偏好或模型学习收益。

[专业来源](https://position-concept.com/portfolio/airbnp-2/)支持短住条件下开放挂衣方便取用的考虑。本轮保留这项供给，具体移动和位置来自研究者对v1餐位路径损失的修订。源项目挂杆由落地双杆替代，房壳6×5×2.6米、初态及12个静态代理均为声明假设；未复现原管线、床内收纳、承重或完整住房功能。[决定包](DECISION_PACKET.json)分开来源、适用条件、假设、对象、实际动作、结果与未知项。
