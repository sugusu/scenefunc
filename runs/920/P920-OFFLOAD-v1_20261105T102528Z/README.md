根据固定序列和4096维BF16隐藏状态，36层输入约2.7–3.3GiB，**这是尺寸估算，不是已测节省量**。模型其他引用、重算工作区及分配器仍可能导致OOM；CPU传输会增加时间。仅包裹检查点入口，保留其内部重算hook；不将整个模型的已保存张量统统复制到CPU。实现依据已核本机PyTorch2.8代码及[官方保存张量说明](https://docs.pytorch.org/docs/2.8/autograd.html#torch.autograd.graph.save_on_cpu)、[检查点说明](https://docs.pytorch.org/docs/2.8/checkpoint.html)。

本轮要验的是训练/保存机制，不是专业学习或新项目设计效果。真实GPU显存与时间尚未验证。新试验如获批准，无论成功失败都报告实际前向/反向/更新数；保存与同进程重载通过也不等于冷启动优化器恢复。
