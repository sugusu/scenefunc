# 专业决定学习修订：同材料与一致终止

本次完成可消费的数据视图和未来执行入口，不启动新训练，也不追加旧权重 Waterloo 推理。原 MATCHEDROLL 结果及严格评分保留。这里是学习试验的组成部分，**不是已经可以批准启动的完整训练卡**：最终训练入口、更新预算、独立评测清单尚未冻结。

## 实际干预与可检验主张

令 I 为相同的原始需求、当前状态、五视图、知识及真实回执，D 为有出处且标明重建的决定记录，A 为动作／停止目标。

- 分开组：学习 D|I，以及 A|I。
- 配对组：学习同一个 D|I，以及 A|I,D。
- 仅动作参照：学习 A|I。冻结底座另配相同知识、充分提示及相同检查反馈。

两组的 D 仍与同一个场景对应。本比较研究“动作训练中接续该决定是否有额外作用”，不声称移除了分开组所有项目对应关系。不能把正确理由胜过错配理由替代这个主对照。

两组各 32 个组件：24 个动作／停止组件与 8 个决定组件，共 1,643 个控制 token 和 1,332 个决定 token。来源仍为 6 个项目族，其中 5 个有理由监督、共 5 条原则。停止陈述不算专业理由；8 个理由位置不等于 8 条独立原则。

配对组的动作组件保留标准 D 作为教师强制上下文，仅监督 A；同一 D 在单独的决定组件中监督一次。决定组件截到工具标记之前，无动作、无 EOS 目标。这是自回归联合目标的分解，没有漏掉第一生成 token，也不额外教“解释完即结束”。旧实验张量与监督保持不变。

项目及分量权重沿用实际 EditTrainer：六个项目族等权，每族分别按动作及理由 token 数归一化，没有理由的族理由项为零。两组每完整遍历监督完全相同材料，各 32 次前向。不是每个理由位置等权，也不是全语料所有 token 简单平均。实际 CPU Trainer 累积误差均 4.07e-8；未运行真实反向。

两组计算不完全相同：配对组每遍历多 1,332 个上下文 token，总序列长度合计高约 0.40%，长度平方和代理高约 0.75%。这不是实际 FLOP 或运行耗时测量。以后须同时报告真实 GPU 时间、显存与完成遍历数，不用 padding 声称计算等价。

## 部署与评分

推理只给 I，不给测试项目标准 D、标准动作或终态。模型自行生成短决定和工具动作；同时报告直接出动作与自行输出决定的比例及结果。不得通过提示强迫分开组只输出理由，或把理由样本结束处误作终止标签。若再比较单独两阶段调用，应让各组共享协议与总生成预算，另列结果。

新的 run_upstream_stop_policy.py 使用锁定上游 parse_assistant_text 提取调用；没有调用即结束，哪怕格式不合格。格式不合格不会制造“拒绝后再试”的反馈循环。格式、终止、当前活动、既有／新增硬失败及解释事实性分别保存。

仍保留现有执行范围：每回合只允许一个经过对象／资产和 schema 校验的调用。多调用拒绝、含调用的截断输出终止且不执行，属于显式局部执行规则，不称与完整上游执行器完全相同。真实模型子进程错误及输出哈希不符均为基础设施错误，首错停止。

新入口已对 35 个存档输出逐一核上游解析，并用 4 个 CPU 服务替身场景执行实际主循环：坏格式无工具停止、正常停止、未闭合 think 内工具执行后停止、首模型错误停止。均保存终态检查；未调用真实模型或原生渲染，不能声称已经改善模型结果。

## 下一学习试验的决策门槛

1. 冻结与本 manifest 兼容的训练入口、参数、有限更新和时间预算，再取得新训练批准。旧 8 更新入口硬编码旧 schema，不能直接改路径冒充可运行。
2. 先检验任务匹配的完整编辑序列。已有两对 Waterloo 同状态不同用途仅作训练域拟合门槛：同时看应保持和必须修改的起点、结束状态和副作用；低动作 NLL 或解释更流畅不够。不能把这个门槛变成新的泛化主测试。
3. 主试验仍需相同动作微调及强提示／同知识检索基线，使用此前开发留出任务，按项目计数。已曝光的 Pine/Milan 只能称开发留出。当前只有 Waterloo 六条输入完成成对均衡，另十八条没有相同级别均衡，不能包装为六族条件反转训练集。
4. 若训练域未学会，定位优化／表示问题，停止跨项目性能主张；若已学会而留出无益，保留负结果，检查适用条件覆盖。训练域过拟合只用来诊断，不是论文成果。
5. 专业决定监督若优于动作参照且不新增硬失败，再用同材料分开组判断增益是否来自动作条件化；最后到未用于迭代的项目验证。所有组均强基线、相同知识和完整房间验收，不故意教错对照。

本批修正了监督材料和执行终止两处可识别问题，没有增加专业来源或独立项目，也没有产生设计学习正结果。下一步应完成一份可直接执行、有决策门槛的学习方案；不再追加相同旧权重的格式／提示微批。
