# 两个整屋迁移任务草案

本轮将 Casa da Porteira 与 Moabit 两个项目家族预先登记为测试候选，排除训练与其他项目检索，再整理来源和任务。它们不是封存测试集。

- Casa：读到建筑师供稿全文；只有约30平方米、屋顶层、露台及原功能组成等少量条件。
- Moabit：取得作者作品页的搜索缓存片段，直接页面403；完整主来源与原始住户任务书仍缺。
- 两份任务的人数、活动关系、矩形边界、层高、门窗及露台尺寸均明确写为研究者设定，不冒充原项目测绘或历史初态。原方案的高柜分隔、抬床等未作为建设要求。

`SOURCE_REVIEW.json`保存出处、核验范围、原文支持内容、成品信息排除项及数值分歧；`TASK_DRAFTS.json`保存完整研究记录；`builder_inputs/`只有草案输入字段。两者均未送入模型。导出校验只证明字段隔离，不证明所有语义无泄漏。

实际CPU导出0.064759秒、exit 0；没有创建原生场景、调用模型或更新权重。厨房、卫浴、收纳、睡眠和活动切换全部保留为要求，未实现的设施不从分母删除。任务阈值、房壳/资产、评价器及方法预算仍须落实，因此正式评价就绪数为0。

这批补的是独立任务准备，不新增专业知识/动作/评价数量。后续需把一个草案落实为真实初态和逐项评价，不能仅增加文档就宣称整屋进展。
