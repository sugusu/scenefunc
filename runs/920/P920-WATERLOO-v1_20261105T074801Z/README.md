# Waterloo：从可变配置理由到实际四步动作

本记录把有出处的选桌决定对应到一间明确声明假设的完整家具场景：分桌配置 → 合桌配置 → 恢复分桌。四次真实原生调用、五组五视图、逐步状态和回执均已保存。它是研究者构建的迁移示范，不是原设计师软件操作，也没有模型或训练结果。

[2022年原项目报道](https://www.nevertoosmall.com/post/waterloo-street-singapore)将住户希望灵活改变配置的需求与Dess Chew选择两张可分可合带轮桌联系起来。来源是Joel Beath对该项目的报道，不冒称建筑师原话。59m²原住宅与本研究8×7×2.6m房壳、1.2×0.7m生成桌、四张凳子分开登记；待客四人和两个分桌工作位置是研究任务设定。原照片未复制。

分桌代理要求两桌间隔≥0.6m；合桌代理要求缝隙≤0.05m、近似平行及同高，四个0.4×0.25m矩形位于桌面，凳子在声明边侧。**这不证明合桌时不能工作，也不证明真人能舒适地就餐。** 三种0.4/0.5/0.6m方形身体、1.8m高度、2cm网格和门全开均为研究假设。所有五个检查点的七项接近均通过；模式所需凳子外侧站立点也可达，坐姿/膝部/同时使用仍未知。

两处转换中间态既未完成分桌配置也未完成合桌配置，转换代价完整保留。最大空矩形在五态均为9.856m²，不能区分模式适用性。27对象保留，25个非目标对象逐字不变；桌和凳无删建或缩放。回位误差：桌约1.94mm/0.156°，凳约0.83mm/0.0085°，不是精确零误差。

固定坐标的桌宽敏感性：95%宽度时缝约8.02cm，105%时包络重叠约0.0277m²；只有实际选用尺寸满足本阈值。该检查只是包络的解析扰动，没有创建新的网格、图像或训练样本。它说明动作坐标必须适配实际资产，不能把本次坐标当成专业原则或泛化证据。
