# 米兰居住兼办公：独立来源任务与条件几何参考

本轮新增一个未进入训练的来源家族，建立带完整生活功能的原生初态，冻结两个办公位置候选。东侧候选实际完成两次家具添加；中央候选因0.6m通路检查失败而未执行。**已有一份几何参考，但不是两个可行方案、模型成果或完整住宅验收。**

## 来源与任务分开

[SET architects原项目说明](https://www.set-architects.com/archives/projects/home-office-in-milan)记述一位年轻委托人希望住宅兼顾居住与工作，分区同时保持视觉连续。原项目2023年建成，报告面积70m²。搜索摘要已暴露部分成品策略，因此此家族虽在全文读取和场景派生前分配test，也不是封存或分析者盲测；底座预训练曝光未知。训练及同知识检索排除该家族。

本任务采用10×7m**总包络**和研究者设置的1.5×1.5m电梯井、卧室/卫浴围护，净面积小于70m²；不是原平面图或面积口径复现。原作者的定制家具以固定目录替代。单人居住、两人用餐、工作资料无需饭前收走、具体初始家具/尺寸/可改范围均为研究假设，原住户原话不可得。模型任务只给用途和已知初态，不给原设计办公角或两个候选坐标。

初态有床、沙发、餐桌两椅、冷藏/备餐/水槽/炉灶、淋浴/洗面盆/厕所、书架，共13家具；11墙体和6开口。固定设施与床不可改，其他家具允许调整但须保留身份和功能，办公位置不指定。当前参考只添加桌椅，未让模型设计，也不是从空壳生成。
