# Casa 整屋推理对照

底座、分开学习适配器、配对学习适配器各进行一次完整房间尝试。后两者仅各训练2次更新。本轮零训练，固定GPU0，使用相同BF16/SDPA、贪心解码、五视图、原始研究任务、16项资产与工具。三个分支从完全相同输入开始，随后按各自真实动作更新观察；不喂入来源事后理由或参考家具坐标。

每组最多24次动作/模型调用，拒绝也计数；包括放置基本设施和修订空间。每次生成最多1024 token，输入最多12288 token，程序完整工具块可提前停止。每组5400秒是执行故障的有限看护上限，不是训练时长或科研目标的截止时间；实际提前完成也保留。首个基础设施错误即停整批，不自动续预算或重试。

先完成一次共同输入编码和原生恢复，再顺序base/separate/paired。入口按实际南侧门，路径代理体宽0.4/0.5/0.6米、高1.8米、1/72米格网，不称人体或法规标准。固定检查露台室内接近点和卫生间内接近点。最终逐项报告九种要求的证据、冲突与未知，家具存在不等于用途完成。安装、门扇隐私、真实收纳容量保持未知。

这是一个未封存、尺寸由研究者设定的来源启发房间和两次更新适配器的描述性比较，不足以证明专业学习、配对收益或跨项目泛化。同知识检索/充分提示和普通动作微调等主对照仍须后续完成。

结果已完成：见 [COMPARISON.md](COMPARISON.md)、[完整数据](COMPARISON.json) 和 [CSV](COMPARISON.csv)。三组各24调用，均有明确功能缺项及两组网格相交；五视图、原生恢复、实际退出和所有小型日志已保留。配对组的露台条件路径在0.5/0.6米下额外失败。该单房间结果不支持配对学习收益或泛化结论。
