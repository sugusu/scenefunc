# 明确当前活动，并把实际执行回执送入训练输入

这批完成的是已有专业决定候选的数据修正。22 个动作、两组共 44 份样本已实际编码，并经训练脚本的 CPU Dataset/Trainer 归一化路径读取；没有训练或新房间生成。

发现的研究问题：Paper 与 Waterloo 的原需求描述了多个活动，部分标准理由却直接假定“来客/共享活动已经结束”。现在给八个动作输入补上明确的当前活动，标为研究者设定，保留原始需求，不提供对象 ID、目标坐标或推荐策略。两组收到完全相同的输入。

必须纠正此前诊断：原候选中已有 17/22 份真实回执，并非普遍没有历史。现在把真实命令、回执和状态哈希放进同一输入格式，区分研究重建与模型执行；回执作为输入屏蔽，不参与预测监督。闭合实验及其结果未改。
