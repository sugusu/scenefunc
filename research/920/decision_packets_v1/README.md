## 重建怎样才能形成有用的样本

**历史实物没有软件 UUID，并不妨碍明确标注的研究者重建。** 给重建初态内的柜体分配代理 ID、保持它跨动作不变，可以测代理实例保留；它不能证明真实旧柜的历史身份。记录语义对应的证据与代理的局限即可，不能把找回 Windows ID 当成所有后续工作的必要条件。

优先推进舞者的整屋活动切换：来源支持的活动条件作为输入，移动茶几的专业理由保留在监督侧；研究者自建的状态与动作须标明重建。输入不得预填来源中的答案动作、目标坐标或来自终稿的活动区域。代理房壳尺寸、门窗及初始摆放都须标明生成假设，后续量测结论仅在该假设下成立。

整屋重建要保留初始对象清单并分别处理地面、墙面、天花和承托物；不能将所有物体投到地面，也不能省略厨房／卫浴来制造空地。若换成真实网格资产，先核尺寸、局部轴、支撑关系及实际碰撞，再决定能否沿用原摆放；不要缩放资产来追求目标分数。

育儿房暂用于实例保留及证据不足的评审开发。完整的外观改造动作需另核墙面／材质／结构能力，当前不构造假的“已完成饰面”监督。可以保留不同可行方案、并列或无法判断；研究者设计的反例不得称作历史被否决方案。
